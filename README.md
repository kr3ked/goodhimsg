# GoodHi для Android

Это проект приложения: внутри лежит ваш мессенджер (`app/src/main/assets/index.html`).
Готовый APK-файл здесь не приложен: его нужно собрать одним из двух способов.

## Способ 1. Через GitHub (без установки программ)
1. Создайте на github.com новый репозиторий и загрузите в него все файлы из этой папки
   (вместе с папкой `.github`).
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
3. Через 3–5 минут внутри завершённой сборки скачайте файл **GoodHi-apk** — там `app-debug.apk`.
4. Отправьте APK на телефон и установите (разрешите установку из неизвестных источников).

## Способ 2. Через Android Studio
1. Установите Android Studio и откройте эту папку (File → Open).
2. Дождитесь синхронизации Gradle.
3. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Что умеет приложение
- Открывает мессенджер на весь экран, кнопка «назад» закрывает чат, окно или историю.
- Выбор фото и файлов из памяти телефона, сохранение файлов в «Загрузки/GoodHi».
- Камера и микрофон для звонков (запрашивает разрешения).
- Демонстрация экрана на Android в WebView не поддерживается.

## Важно про друзей и звонки
В таком виде мессенджер хранит всё на самом телефоне. Друзья с других телефонов не увидят
друг друга. Чтобы друзья на разных телефонах переписывались и звонили, нужна серверная версия
(`goodhi-fixed.zip`) на вашем https-сайте. Тогда в `app/build.gradle` замените `START_URL`
на адрес сайта, например `"https://goodhi.example.com"`, и соберите приложение заново.
