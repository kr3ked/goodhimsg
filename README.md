# GoodHi: мессенджер + админ-база на GitHub Pages

Файлы:
- `index.html`: мессенджер (ваш, с кнопкой «Пожаловаться» и синхронизацией в базу)
- `admin.html`: админ-панель (пользователи, истории, чаты, жалобы → «Забанить» / «Удалить жалобу»)
- `config.js`: ключи вашего Firebase-проекта
- `database.rules.json`: правила безопасности базы

## Настройка (10 минут, бесплатно)

1. Зайдите на https://console.firebase.google.com → **Add project**.
2. **Build → Realtime Database → Create database** (любой регион). Скопируйте URL вида
   `https://xxxx-default-rtdb.firebaseio.com`.
3. **Build → Authentication → Get started → Email/Password → Enable**.
   Затем вкладка **Users → Add user**: создайте аккаунт администратора (почта + пароль).
4. **Project settings (шестерёнка) → General → Web API Key**: скопируйте.
5. Откройте `config.js` и впишите `dbUrl` и `apiKey`.
6. В Realtime Database откройте вкладку **Rules**, вставьте содержимое `database.rules.json`,
   **замените `ADMIN@EXAMPLE.COM` на почту админа из шага 3** (везде, 5 мест) и нажмите **Publish**.
7. Загрузите все файлы в репозиторий GitHub → Settings → Pages → Deploy from branch.
8. Админка: `https://ВАШ_НИК.github.io/РЕПО/admin.html`.

## Как это работает

- Каждый раз, когда пользователь что-то меняет, мессенджер отправляет в базу профили, истории
  (с миниатюрой фото), список чатов (участники и количество сообщений) и жалобы.
  Текст личных сообщений в базу **не отправляется**.
- «Пожаловаться» находится в профиле пользователя (нажмите на аватар/имя → внизу).
- **Забанить** записывает почту в `bans`. Мессенджер проверяет бан при входе и каждые ~15 секунд
  у вошедшего пользователя, поэтому он сразу вылетает. Заодно удаляются все жалобы на него.
- **Удалить жалобу** просто убирает её из базы. **Разбанить** есть во вкладке «Пользователи».

## Важно знать

- **Аккаунты, друзья и переписка теперь синхронизируются через Firebase** между всеми устройствами.
  Узлы базы: `profiles`, `unames` (вход и поиск), `rel` (друзья и заявки), `dm` (сообщения),
  `rcpt` (статусы «доставлено/прочитано»).
- В облако уходят **только текстовые сообщения** личных чатов. Фото, файлы, свои стикеры, истории,
  «Избранное» и звонки остаются на устройстве.
- **Приватность.** Тексты сообщений лежат в базе. Прочитать переписку может тот, кто знает
  обе почты участников (путь чата строится из них). Сообщения нельзя изменить или удалить через базу.
  Полностью закрыть чтение можно только переходом на Firebase Authentication.
- Запись в `profiles`, `rel` и `rcpt` открыта всем (вход в мессенджер идёт не через Firebase Auth),
  поэтому злоумышленник технически может подделать профиль или заявку.
- Чтобы работало, все пользователи должны открыть новую версию `index.html` и войти один раз:
  тогда их профиль попадёт в облако.

## Push-уведомления (когда приложение закрыто)

Нужны: тариф Firebase Blaze (карта, но на вашем объёме бесплатно), компьютер с Node.js 20.

1. В папке `push-server/functions` скопируйте `.env.example` в `.env` и вставьте ключи.
   Ключи создаются командой `npx web-push generate-vapid-keys` (публичный и приватный).
2. В папке `push-server/functions` выполните `npm install`, затем в `push-server`:
   `firebase login` и `firebase deploy --only functions`.
3. В `config.js` внутри `window.GH_CFG` добавьте строку `push: { vapid: "ПУБЛИЧНЫЙ_КЛЮЧ" },`.
4. Вставьте `database.rules.json` в Firebase Rules (добавлен узел `push`) и загрузите `index.html`, `sw.js`.
5. В приложении: Настройки → Push-уведомления → «Включить».

## Группы и каналы

- **Создание:** кнопка «новый чат» → «Создать группу» или «Создать канал». Можно сразу выбрать друзей и задать публичное @имя.
- **Группа:** писать могут все участники. **Канал:** пишут владелец и назначенные им администраторы, остальные читают.
- **Приглашение:** у каждой группы и канала есть код и ссылка (шапка чата → информация). Вступить можно по коду, по @имени или по ссылке `...?join=КОД`.
- **Роли:** владелец назначает администраторов и удаляет участников и группу; админ добавляет друзей и убирает обычных участников.
- В группах и каналах синхронизируются текст, голосовые и кружки. Стикеры и файлы пока только в личных чатах.
- Права проверяются приложением, а не базой (в проекте нет Firebase Auth), поэтому надёжной защитой от злоумышленника они не являются.

## Обновления «по воздуху»

Приложение само проверяет новую версию при открытии, раз в 5 минут и при возврате в приложение.
Если нет черновика, звонка и открытых окон, оно обновляется само. Иначе показывает плашку «Обновить».
Проверить вручную: Настройки → Приложение → «Проверить обновления».

Чтобы выпустить новую версию, загрузите новый `index.html` в репозиторий. В файле меняется строка `const APP_VER='...'`
(номер версии), по ней устройства понимают, что есть обновление.

## Формы кружков

Доступны три формы: круг, капля и квадрат (Настройки → «Голосовые и кружки»). Старые кружки с другими формами показываются кругом.
